Không có một stack bắt buộc cho mọi sinh viên IT, nhưng có những năng lực nền giúp bạn học hướng nào cũng nhanh hơn. Sai lầm phổ biến là học tên công nghệ trước khi biết mình đang giải quyết vấn đề gì.

## Tầng 1: một ngôn ngữ và tư duy giải bài

Chọn ngôn ngữ đang dùng ở trường hoặc phù hợp mục tiêu gần nhất. Python dễ bắt đầu; C/C++ giúp thấy rõ kiểu dữ liệu và bộ nhớ; Java/C# tốt cho OOP và hệ sinh thái doanh nghiệp. **Không cần học cả ba cùng lúc.**

Bạn cần làm được:

- chia bài toán thành hàm/bước nhỏ;
- dùng điều kiện, vòng lặp, cấu trúc dữ liệu cơ bản;
- đọc lỗi và debug;
- viết test case nhỏ;
- giải thích code bằng lời.

## Tầng 2: công cụ làm việc

Học Git đủ để `clone`, tạo branch, commit có nghĩa, đọc diff, xử lý conflict đơn giản và mở pull request. Học terminal để di chuyển file, chạy lệnh và đọc output. IDE chỉ hỗ trợ; đừng phụ thuộc vào nút Run mà không biết lệnh nào chạy phía sau.

## Tầng 3: dữ liệu và kết nối

SQL, mô hình quan hệ, khóa, join và normalization cơ bản hữu ích cho Developer, Data Analyst, Data Engineer, BA và QA. Đồng thời hiểu HTTP, request/response, status code và JSON để giao tiếp giữa hệ thống.

## Tầng 4: chất lượng

Biết viết README để người khác chạy project, kiểm tra input sai, ghi bug có bước tái hiện và dùng test. “Chạy được trên máy em” chưa phải sản phẩm hoàn chỉnh.

## DSA và OOP học tới đâu?

**DSA:** học chắc cấu trúc cơ bản, độ phức tạp và lý do chọn; không nhất thiết cày contest nếu hướng nghề không cần, nhưng không nên mù về hiệu năng.

**OOP:** hiểu encapsulation, composition, interface và trade-off. Đừng học thuộc bốn tính chất mà không thể thiết kế một ví dụ nhỏ.

## Chọn nhánh sau nền tảng

- **Developer:** project end-to-end, framework, deployment, testing.
- **Data Analyst:** spreadsheet, SQL, thống kê, BI và kể chuyện bằng dữ liệu.
- **Business Analyst:** khám phá yêu cầu, quy trình, domain và giao tiếp stakeholder.
- **Data Engineer:** Python/SQL, data modeling, pipeline và hệ phân tán sau này.
- **QA/Tester:** test design, bug report, API test; automation sau khi hiểu chất lượng.

Bạn có thể thử mỗi hướng bằng một project nhỏ 1–2 tuần trước khi mua khóa dài.

## AI-assisted coding nằm ở đâu?

Dùng AI sau khi bạn có thể mô tả yêu cầu, đọc diff và chạy test. Yêu cầu AI giải thích lựa chọn, tạo test hoặc phản biện. Không merge code bạn không thể debug. Kỹ năng quan trọng không phải viết prompt “thần thánh”, mà là kiểm soát đầu vào, đánh giá đầu ra và chịu trách nhiệm.
